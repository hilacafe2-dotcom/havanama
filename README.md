# هوانما – اپ اندروید کیفیت هوا

صفحه‌ی `www/index.html` داخل یک اپ اندروید (Capacitor) قرار گرفته است.
در اپ اندرویدی، کد ابتدا تلاش می‌کند از `CapacitorHttp` بومی استفاده کند تا محدودیت CORS مرورگر دور زده شود. اگر صفحه را مستقیماً در مرورگر از مسیر `file://` باز کنید، درخواست عادی `fetch` ممکن است به CORS برخورد کند. دسترسی شبکه و پذیرش درخواست توسط سرور DOE همچنان باید آزمایش شود.

## ساخت APK با GitHub (بدون نصب چیزی)
1. در github.com یک repository خصوصی بساز و همه‌ی فایل‌های این پوشه را در آن آپلود کن
   (پوشه‌ی `.github` را هم حتماً؛ اگر آپلود نشد، فایل `.github/workflows/build-apk.yml` را با Add file → Create new file بساز).
2. تب **Actions** → «Build APK» → Run workflow (یا همان‌جا بعد از آپلود خودکار اجرا می‌شود).
3. بعد از ~۵ دقیقه، داخل اجرای تمام‌شده، پایین صفحه در **Artifacts** فایل `havanama-apk` را دانلود کن، از zip بیرون بیاور و `app-debug.apk` را روی گوشی نصب کن.

## ساخت با Android Studio
```
npm install
npx cap add android
npx cap sync android
npx cap open android
```
بعد در Android Studio: Build → Build APK(s).

## فونت
فونت وزیرمتن هنگام ساخت (GitHub Actions) از npm برداشته و داخل اپ گذاشته می‌شود. اگر با Android Studio می‌سازی، بعد از `npm install` این را اجرا کن:
```
mkdir -p www/fonts && cp "$(find node_modules/vazirmatn -iname '*wght*.woff2' | head -n 1)" www/fonts/Vazirmatn.woff2
```

## تغییر در صفحه
فایل `www/index.html` را ویرایش کن، سپس دوباره ساخت را اجرا کن.


## نسخه اصلاح‌شده برای اتصال DOE

- این نسخه دیگر در زمان شکست درخواست DOE به Open-Meteo برنمی‌گردد؛ در نتیجه داده مدل‌سازی‌شده به‌عنوان داده رسمی نمایش داده نمی‌شود.
- پردازش پاسخ DOE برای چند قالب رایج و AQI عددی یا رشته‌ای مقاوم‌تر شده است.
- خطای درخواست یا ساختار پاسخ در صفحه نشان داده می‌شود تا تشخیص علت مشکل آسان‌تر باشد.
- آدرس فعلی DOE در `www/index.html` قرار دارد. اگر اتصال مستقیم در مرورگر به علت CORS مسدود شد، باید یک واسط HTTPS متعلق به خودتان تنظیم کنید و مقدار `DOE_URL` را به آدرس آن تغییر دهید.
- **مهم:** این بسته به‌تنهایی تضمین نمی‌کند که سرور DOE درخواست را از همهٔ شبکه‌ها بپذیرد یا ساختار پاسخ زنده دقیقاً مطابق فرض‌ها باشد. پس از اجرا، اگر خطا نمایش داده شود، متن خطا را برای تشخیص مرحله بعد بفرستید.


## تغییرات نسخهٔ تشخیصی ۲
- درخواست DOE در اپ Capacitor با `CapacitorHttp.get` انجام می‌شود، نه فقط `fetch` مرورگر.
- خطاهای شبکه با جزئیات بیشتر نمایش داده می‌شوند.
- پاسخ DOE همچنان باید در اجرای واقعی آزمایش شود؛ اگر سایت قالب متفاوتی برگرداند، لازم است parser بر اساس پاسخ واقعی اصلاح شود.
- هنگام تغییر کد، برای تست واقعی اندروید حتماً APK را دوباره بساز و نصب کن. ویرایش `www/index.html` به‌تنهایی APK نصب‌شده را به‌روزرسانی نمی‌کند.


## نسخه اصلاح اتصال CapacitorHttp
این نسخه `CapacitorHttp` را از `@capacitor/core` به‌صورت مستقیم import و با esbuild داخل `www/app.js` بسته‌بندی می‌کند. برای تست، APK را از workflow همین ZIP دوباره بساز و نصب کن. اگر بعد از این تغییر خطا با برچسب `CapacitorHttp` دیده شد، دسترسی سرور DOE یا پاسخ آن باید جداگانه بررسی شود.
